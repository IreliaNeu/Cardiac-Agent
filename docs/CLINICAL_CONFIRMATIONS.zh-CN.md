# 与医工老师确认的需求清单

日期：2026-09-20。建议第一次讨论优先完成 P0 项，再决定训练与论文实验设计。
现有 CAMUS 标注是分割标签；当前系统没有训练好的 RWMA 分类器。

## P0：决定研究任务和可行性

| 需要确认 | 请老师给出的具体信息 | 对实现和实验的影响 |
| --- | --- | --- |
| 首要临床终点 | 是病例级 RWMA、节段级 RWMA，还是整体收缩功能异常？能否用一句话定义主要任务？ | 决定模型输出与评价真值；三种任务不能共用一个标签解释 |
| 数据范围 | 病例数、正常/异常数、每患者检查次数、机构/设备、A4C/A2C 等切面；是否有完整 cine？ | 判断能否训练、类别不平衡、跨设备验证和是否需要时序模型 |
| RWMA 标签来源 | 医生独立阅片、原始报告还是专门标注？标签是患者/检查/切面/节段级？如何对应图像？ | 确定监督目标，防止将报告结论误配到帧或切面 |
| 标注与分歧 | 标注者资历与数量、是否独立盲评、意见冲突如何仲裁、能否抽样复核？ | 决定标签可靠性与读者一致性实验 |
| 时相选择 | ED/ES 如何定义和定位？同一心动周期吗？有 ECG、时间戳、帧率、心律失常信息吗？ | 决定稀疏运动信号是否可解释、能否进行完整周期对照 |
| 分割对象 | 仅左室腔，还是需要心肌/心内膜/心外膜？标注是否包含乳头肌、心尖和瓣环？ | 决定分割协议和运动特征对应的解剖结构 |
| 去重与划分 | 能否提供稳定的匿名患者 ID；重复检查能否归组；是否预留独立外部测试集？ | 防止同一患者或同一视频的帧进入训练和测试两侧 |

## P1：决定结果如何解释与评价

| 需要确认 | 建议讨论内容 | 当前默认处理 |
| --- | --- | --- |
| FAC 的用途 | FAC 在本研究切面/人群中是描述性指标还是有经验证的判别依据？是否需要双平面容积/EF？ | 仅报告面积变化，不等同于 LVEF，不自行设异常阈值 |
| 运动证据 | 腔内光流是否满足研究目标，还是需要心肌/轮廓跟踪？如何标注可信/不可信运动？ | Farneback 是工程基线，不能命名为心肌应变 |
| 图像质量 | 低质量、心尖截短、遮挡、瓣环定位不清、心律不齐如何排除或分层？ | 保留失败记录，不能只统计成功病例并隐藏分母 |
| 主要评价指标 | 分割 Dice/HD95、功能量误差；RWMA 的敏感度、特异度、AUROC、校准等如何排序？ | 现有 Dice/IoU、面积与 FAC 误差；分类无模型时不报性能 |
| 模型拒答 | 哪些质量问题需要拒答/复核？概率阈值与漏诊、误报代价如何确定？ | unavailable/abstained 独立记录，不转为“正常” |
| 临床解释 | 报告用中文还是英文？允许哪些措辞？能否给 5–10 份合格与不合格示例？ | 只生成可核对事实，不下“功能正常/异常”结论 |
| 问答金标准 | 设计哪些问题？每题证据来源、可回答/不可回答条件及医生答案是什么？ | 三项工程 QA；“收缩功能下降”与“RWMA”不视为同义 |
| 医生评价 | 是否可以盲评、几位医生、评价数值一致性/依据完整性/可用性中的哪些维度？ | 目前自动核验只证明事实传递一致 |

## P2：交付与论文设计

1. 明确预期使用者和场景：研究演示、辅助阅片还是报告整理；是否必须支持视频和多切面。
2. 确定最低可接受的运行时间和展示内容：原图、mask、差异图、数值、解释、可追溯证据。
3. 确认数据使用范围与发布边界；已有“医学指标可发送千问 API”的工程授权继续有效。
   若未来引入医院原始图像到外部 VLM，需另行明确原始图像的使用方案。
4. 确认论文主要假设：稀疏时相特征能否预测 RWMA？ROI 是否改善结果？解释是否提高可用性？
5. 设计必要对照：人工/预测 mask、FAC 单特征/加运动/加图像特征、传统分类器/MLP、
   两帧/完整周期、模板/证据约束 LLM，以及分割误差向下游的传播。
6. 根据病例数与类别分布确定样本量和统计方案；当前 3 例只用于流程验证。
