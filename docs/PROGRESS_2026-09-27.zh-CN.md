# 2026-09-27：三角色单轮与 CAMUS 百例验证

## 本轮范围

根据用户要求实现 Planner、Analyst、Reviewer 三角色单轮交互，计划固定运行 100 位 CAMUS 患者
的 A4C ED/ES 图像对，输出原图、预测分割、叠加图及模型生成报告。实验文件仅保存在服务器，
本地和 GitHub 仅保留代码框架、配置、测试与技术文档。本轮结束后需校验、归档并关闭服务器。

## 已完成实现

- 增加独立 `discussion.py`；复用原确定性流水线，不改写基础分割/测量逻辑。
- Planner 可选择面积分析或面积加稀疏光流；Analyst 生成草稿；Reviewer 单次审查并形成最终报告。
- 三角色均采用 Qwen API，当前配置为 SiliconFlow `Qwen/Qwen3-30B-A3B-Instruct-2507`。
- 每例仅三个角色回合；有请求哈希缓存，禁止对失败/未落盘响应静默重新生成。
- 参考 mask 不用于预测，参考分数不进入模型提示；原图也不发送给 API。
- 新增并发下载/批处理脚本、统一病例结果目录、独立指标评估和只读验收脚本。
- 证据键值精确一致校验；正文数字可按证据进行十进制舍入，保留不可修改的完整数值表与局限声明。
- QC 强制人工复核覆盖模型建议；保留模型原始意见，便于追踪差异。
- 新增中文技术文档 `THREE_ROLE_WORKFLOW.zh-CN.md`，更新英文 README。

保守分析的路径。此预验证用于冻结工程实现，不作为独立性能证据。

测试：48 项通过；Ruff 通过。新增用例包括三个角色各一次、参考信息隔离、断点不重复请求、
QC 强制复核、篡改数值拒绝、正确舍入接受、重复 JSON 字段拒绝、源图改变后缓存失效、
仅补齐未发言角色，以及二次 JSON 编码证据的无损解码。

## 当前问题与后续工作

1. 仅有双帧，不具备完整周期或分区心肌运动证据；RWMA 分类器仍未训练和验证。
2. 三角色共用一个模型，错误可能相关；尚未证明优于固定流水线或等预算单模型。
3. 数值校验属于词法约束，不能识别所有指标关联、单位、中文数字及医学语义错误。
4. 现有 QC 主要检查触边及面积顺序，不能可靠识别全部低质量分割；需增加无真值质量评估。
5. 待与医工老师明确目标病种/终点、分区与视频可用性、报告盲评标准、人工复核门槛和正式患者级划分。
6. 后续再设计工具恢复策略、经审核的病例记忆和三角色消融；本阶段不启用长期记忆或自由讨论。
