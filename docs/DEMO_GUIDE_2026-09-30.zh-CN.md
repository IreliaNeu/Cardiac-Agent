# Cardiac Agent 项目技术报告

2026 年 9 月 30 日 | 对应 2026 年 9 月 27 日百例封存结果

## 摘要

Cardiac-Agent 是面向心脏超声图像分析的研究原型，集成双时相图像输入、左室心腔分割、面积测量及三角色报告生成与审查。系统将图像计算与语言解释分离，通过结构化证据包连接定量工具与语言模型，保存图像、测量结果、质量控制标记及角色调用记录，以支持结果追溯和失败分析。

基于 CAMUS A4C 双时相图像开展的百例流程验证中，98 例完成数值计算，2 例因空分割失败；整理后的交付目录包含 100 份报告。全百例平均 Dice 为 0.8082；可计算的 98 例 FAC 平均绝对误差为 9.79 个百分点。当前证据支持单轮受约束工作流的工程可行性，尚不足以证明多角色协作的独立收益或临床有效性。

## 研究设计与报告范围

| 分析层面 | 当前实现 | 评价重点 |
| --- | --- | --- |
| 图像与测量 | ED/ES 分割及面积计算 | 分割重合度、测量偏差与失败率 |
| 多角色交互 | Planner、Analyst、Reviewer | 工具选择、证据一致性与质控约束 |
| 案例分析 | 五类目的性选例 | 较好结果、误差抵消、漏检与失败 |
| 后续验证 | 医学任务及评价方案待确定 | 临床终点、独立测试与医生评阅 |

报告包括输入与指标定义、系统架构、角色交互机制、百例结果、五例分析以及后续验证需求。五例依据预先说明的筛选规则进行目的性选择，用于分析不同运行状态，不作为随机或临床代表性样本，也不用于重新估计总体性能。

## 阶段性结论

系统已形成从预测分割到定量证据、再到中文报告的可追溯链条。案例分析显示，较小的 FAC 误差可能伴随系统性欠分割，面积顺序合理也不能保证预测区域正确。因此，下一阶段的核心工作是建立可靠的分割质量评价与医学审核标准，并通过对照实验验证角色协作的实际作用。

关键词：心脏超声；左室分割；结构化证据；多角色协作；质量控制。

## 1 数据输入与评价指标

本阶段使用 CAMUS 心脏超声心尖四腔心（A4C）图像，每例包含一张舒张末期（ED）图像和一张收缩末期（ES）图像，不包含完整心动周期视频。人工掩码（mask）中的左室（LV）心腔标签用于独立评价，不作为预测模型或报告生成模块的输入。

| 对象 | 当前用途 | 使用边界 |
| --- | --- | --- |
| ED 和 ES 原图 | 本地分割模型输入 | 不提供连续运动轨迹 |
| 预测 LV 二值 mask | 面积计算与可视化 | 与人工标注独立保存 |
| 人工 LV mask | Dice、IoU 与参考 FAC 计算 | 不进入 Agent 上下文 |
| 结构化测量证据 | Analyst 和 Reviewer 的依据 | 不替代图像质量审查 |
| 中文报告 | 对证据及局限的研究性解释 | 不构成临床诊断 |

## 指标定义

面积 A 为预测 mask 的非零像素数，单位为像素。代码支持在具备可靠像素间距时计算物理面积；本报告中的像素计数未转换为平方毫米。

面积比 R = A_ES / A_ED。

FAC = 100 × (A_ED − A_ES) / A_ED，单位为百分比。这里的 FAC 是双帧心腔面积变化率，不是左室射血分数 LVEF。FAC 绝对误差以百分点 pp 表示，例如 30% 与 20% 相差 10 pp。

Dice = 2 × 预测与人工交集 / 两者像素数之和；IoU = 交集 / 并集。展示页的“平均 Dice”先对单例 ED、ES 求均值；批次均值再对病例求均值。数值接近不能替代轮廓空间重合的检查。

## 输入不足时的处理

ES mask 为空时不输出 FAC 或面积比，避免把无法分割误写为完全收缩。ES 面积不小于 ED 时触发顺序异常质控，并要求人工复核。仅凭双帧心腔面积，不能判断局部室壁运动正常或异常。

面积变化指标与后续医学研究终点的对应关系仍需确定。若研究转向体积或时序功能评价，应补充相应输入、测量协议与验证参照；现有 FAC 结果不能直接替代 LVEF。

## 2 系统架构与模块职责

流程主线如下；人工参考评价是旁路，不回流到语言模型。

输入 ED/ES 原图与元信息

↓ Planner 读取元信息，选择面积分析或附加探索性光流

↓ 本地 EchoNet DeepLabV3 ResNet50 分割 → ED/ES 预测 mask

↓ 确定性工具计算面积与 FAC → QC 标记 → 结构化证据包

↓ Analyst 读取计划与证据 → 生成报告草稿

↓ Reviewer 读取同一证据与草稿 → 生成最终报告及 limited/refer

↓ 程序执行硬性 QC 约束 → 保存图像、数值、报告和角色记录

独立评价旁路：预测 mask + 人工 LV mask → Dice/IoU 与 FAC 参考误差 → 评估文件和展示对照图。

| 模块 | 主要文件 | 职责 |
| --- | --- | --- |
| 数据与契约 | camus.py / schemas.py | CAMUS 转换、时相与输入结构 |
| 分割工具 | roi.py | 加载分割模型并生成 mask |
| 测量与证据 | function.py / pipeline.py | 面积、可选光流、QC、证据与来源记录 |
| 局部运动接口 | rwma.py | 未部署有效分类器时明确不可用 |

计算部署：分割在服务器本地执行；语言模型通过 API 调用。演示回放不需要 GPU、API key 或模型服务。原图和人工标注不发给语言模型。

## 3 三角色交互与执行约束

三角色本轮使用相同的 Qwen/Qwen3-30B-A3B-Instruct-2507，服务来自 SiliconFlow。它们是不同角色提示和输入上下文下的三次调用，不是三个独立训练的模型。

| 角色 | 输入信息 | 输出与权限 |
| --- | --- | --- |
| Planner | 视图、尺寸、ED/ES 信息、可用工具 | none/farneback 与分析重点；不能看图诊断 |
| Analyst | 计划、程序算出的数值、QC 与固定局限 | 保留原数值的 evidence 和中文草稿 |
| Reviewer | 同一证据包及 Analyst 草稿 | 最终文字、concerns、limited 或 refer |

本轮每例只有 Planner → 工具 → Analyst → Reviewer 一次顺序执行。Reviewer 不重新调用分割工具，不启动第二轮讨论。百例中 Planner 全部选择 none / area_only，因此没有通过这批数据验证工具规划的多样性或光流带来的收益。

## 程序约束与剩余盲点

程序要求报告中的 evidence 字典与输入完全一致，并校验文字中的阿拉伯数字是否可由输入数值按规定舍入得到。该检查能防止一部分数值捏造，但不能证明单位、因果关系、比值方向或中文数量表达都正确。

触边、面积不递减等阻断 QC 会强制最终状态为 refer；模型不能将其改为放行。limited 只表示受限研究输出，不表示临床正常；refer 表示需要人工复核，不表示阳性疾病。

角色请求与回应、请求哈希、模型信息和调用遥测均保留。相同请求可复用缓存，已失败的角色尝试不自动重放，以避免把重试伪装成一次讨论。这是过程缓存，不是长期记忆。

## 自主性与能力边界

尚无自由多 Agent 辩论、自主修复闭环、经验证的 RWMA 分类器、临床知识检索或长期病例记忆。Farneback 接口只支持探索性稀疏心腔运动，不等同于心肌应变。三角色提示不同也不意味着审查意见相互独立。

当前 Agent 的自主性主要体现为有限工具选择与证据审查。扩大工具权限或增加讨论轮数前，需要通过与单次报告生成的对照实验，评估其对事实一致性、失败检出和调用成本的影响。

## 4 百例结果与评价口径

结果来自 three-role-100-20260927-delivery；原始实验目录保持不变。下列数字衡量流程与分割结果，不是临床诊断准确率。

| 项目 | 结果 | 分母或解释 |
| --- | --- | --- |
| 数值计算完成 | 98 例 | 100 个请求病例 |
| 空 ES mask 失败 | 2 例 | patient0033、patient0068 |
| 最终报告齐全 | 100 份 | 含 2 份明确失败报告 |
| 三角色调用记录 | 300 次 | 每例各 1 次，每次 HTTP 尝试为 1 |
| 全部病例平均 Dice | 0.8082 | 包括失败，共 100 例 |
| 全部病例平均 IoU | 0.7009 | 包括失败，共 100 例 |
| 完成计算病例平均 Dice | 0.8185 | 98 例 |
| 完成计算病例平均 IoU | 0.7107 | 98 例 |
| FAC 平均绝对误差 | 9.79 pp | 仅可计算的 98 例 |
| 强制人工复核 | 4 例 | 2 个面积顺序异常及 2 个空 mask |

完整性审计核验了 2599 个文件，并确认原图 200 张、二值预测 200 张、叠加图 200 张与 100 份报告。完整性通过只说明产物和记录一致，审计没有检查临床正确性。

两个空 mask 病例在独立交付整理阶段导出诊断性分割结果，并补齐尚未执行的 Analyst/Reviewer，已缓存的 Planner 不重跑。人工 mask 没有用于修补预测；失败病例仍不计入 FAC 误差的有效分母。

## 实验设计的局限

首批 3 例曾用于开发且包含在百例中，本批不能称为独立留出测试。patient0033 与 patient0068 的 ED 图像哈希相同，ES 不同；100 对 ED/ES 的组合不同，但划分数据时仍需检查重复图像和患者来源。

当前尚未开展匹配预算的单 Agent、固定流水线和三角色对照，也未进行医生盲评及临床终点标签验证。因此，本批结果属于可追溯流程的工程验证，不能据此推断多 Agent 对临床准确率的改善。

## 5 较好结果与误差抵消

### patient0020 完整链条示例

筛选规则：当前 QC 未触发、最终 limited 且 FAC 绝对误差不超过 5 pp 的病例中，选择 Dice 最高者。5 pp 仅为演示筛选规则，不是临床阈值。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 43169 | 45007 |
| ES 心腔像素数 | 30343 | 32117 |
| FAC | 29.7111% | 28.6400% |
| ED / ES Dice | 0.9543 / 0.9192 | 平均 0.9368 |
| FAC 绝对误差 | 1.07 pp | 状态 limited |

原图、预测叠加和双轮廓对照形成了该例的图像证据。面积及 FAC 来自预测 mask；人工轮廓仅用于独立评价。三个角色的原始记录保留了计划、证据到报告的传递过程。

该例预测与人工轮廓具有较高重合度，FAC 与人工参考较为接近，可用于说明完整处理链条在较好分割条件下的输出特征。其选择具有明确目的性，不代表全体病例表现。

### patient0004 两相位同时少分

筛选规则：选择 Dice 最接近完成计算的 98 例中位数的 QC 清洁病例。该批中位数为 0.8616；本例均值为 0.8622。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 24049 | 31799 |
| ES 心腔像素数 | 14154 | 18605 |
| FAC | 41.1452% | 41.4919% |
| FAC 绝对误差 | 0.35 pp | 状态 limited |

两相位都少分了约四分之一，面积比却相近。说明 FAC 误差小可能来自误差抵消，不一定表示边界分割准确。接近本批中位数，也不意味着具有临床代表性。

该结果提示，后续评价宜同时考虑分割边界、测量偏差和失败检出能力，避免仅依据面积变化误差评价系统质量。

## 6 当前 QC 的盲点与有效拦截

### patient0042 报告流畅但分割严重偏差

筛选规则：当前 QC 未触发且最终 limited 的病例中，选择平均 Dice 最低者。这一例用于暴露盲点，而不是展示整体均值。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED / ES 像素数 | 17990 / 12078 | 31269 / 24566 |
| FAC | 32.8627% | 21.4366% |
| ED / ES Dice | 0.6294 / 0.0868 | 平均 0.3581 |
| FAC 绝对误差 | 11.43 pp | limited；当前 QC 未触发 |

ES 双轮廓对照显示，虽然预测像素数量仍满足 ES 小于 ED，但预测区域与人工区域的重合度很低。Reviewer 的输入不包含原图或人工 Dice，仅依靠数值顺序无法识别这类空间错误。

原报告中的比值表述应按结构化字段 ES/ED 理解，不能把文字中含混的“ED 与 ES 面积比值”当作定义。页面保留原报告，并把这项解释放在独立旁注中。

该例反映了现有证据接口的不足：语言审查无法补足未被提供的图像质量信息。后续可引入不依赖人工标签的分割质量评估，并检验 Agent 对质量信号的使用是否改善错误检出。

### patient0039 顺序异常被强制转人工

筛选规则：完成计算且被 QC 转人工的病例中，选择平均 Dice 最低者。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED / ES 像素数 | 18989 / 27515 | 34118 / 19433 |
| FAC | −44.8997% | 43.0418% |
| 平均 Dice | 0.0088 | FAC 误差 87.94 pp |
| 处置 | refer | 面积顺序 QC 强制复核 |

负 FAC 是程序对异常预测面积按公式计算的结果，不是负射血分数，更不是疾病结论。需要医生回看图像核查分割和时相。该例证明一条规则能够发现某类异常，但不能推论它能覆盖上一例那样的空间错位。

## 7 空分割及报告语义问题

### patient0033 空分割与失败记录

筛选规则：按病例编号选择第一个已生成失败报告的空 mask 病例。它的 ES 二值图为全零，预测叠加图中没有绿色区域，并非展示页加载失败。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 13461 | 31077 |
| ES 心腔像素数 | 0 | 13219 |
| ED / ES Dice | 0.6045 / 0.0000 | 平均 0.3022 |
| 模型 FAC 与面积比 | 不可用 | 人工参考仅用于独立评价 |
| 处置 | refer | 空预测 mask，工具失败报告 |

ES 二值预测为空，而人工参考中仍存在心腔区域。系统保留了该失败状态，并将 FAC 与面积比标为不可用，未使用人工 mask 替换预测，也未将空 mask 错误解释为 FAC 等于 100%。

## 原始报告的语义偏差

原文称“ED相位掩码有效”。现有证据最多支持它非空，不能据此说分割准确。本例 ED Dice 为 0.6045，必须区分格式或可计算性与解剖准确性。

原文把 RWMA 不可用归因于输入缺失，也不完整。当前项目实际上没有部署经验证的 RWMA 分类器，即使分割成功，也不能生成可靠的局部室壁运动分类。

上述句子作为原模型输出予以保留。独立分析说明与原始报告分开记录，不作为模型修订结果。该例表明，保持 evidence 数值一致并不能保证解释语义正确。

## 失败状态建模建议

建议将可计算、分割可信和临床可解释分为不同状态；报告中分别列出“工具未部署”“输入不足”“QC 阻断”。对失败原因采用可追踪错误码，并检查模型文字是否与错误码一致。

完整评价应同时报告总请求数、测量成功数、失败原因和条件性能。保留失败病例有助于避免仅统计成功样本造成的选择偏倚。

## 图像与记录的组织

每例按 ED 和 ES 分组展示原图、绿色预测叠加及双轮廓对照。青色表示预测轮廓，橙色表示人工 LV 轮廓。人工对照用于结果分析与独立评价，未进入 Agent 的输入上下文。

病例记录依次关联原始图像、预测结果、独立评价及模型报告。三个角色的输出单独保存，结构化记录支持回查请求与响应。页面补充说明与原模型报告分开呈现，以保留证据来源。

代码环境使用 cardiac-agent-gpu；导出脚本本身无需 GPU。已有封存结果的哈希在导出前后校验，导出不修改原始百例、不重跑模型、也不发 API 请求。

## 9 医学验证需求与后续工作

### 研究终点

分割质控、定量测量解释和局部室壁运动异常（RWMA）判别对应不同的输入与标签需求。后续需由医学合作方共同确定优先研究终点、目标解剖结构、视图、疾病范围及预期使用者，据此制定完整视频、多视图或其他临床信息的采集方案。

### 统一标注和测量协议

待确认内容包括 LV 边界标注口径、ED/ES 选帧规则、像素间距可靠性、多位医生标注及争议仲裁机制，以及 FAC 的适用参照。临床分层阈值需具有明确依据，不由语言模型自行设定。

### 拒答与人工复核标准

医学评阅需覆盖分割可接受性、测量可用性、必须拦截的错误类型及可能产生误导的报告措辞。“数值合理但区域错误”的病例是重点分析对象，可用于制定形状、视图、置信度或时序一致性质量评价标准。

### 设计报告评价

建议盲评事实一致性、错误归因、限制说明、遗漏和潜在误导，同时记录修改时间。把结构化 evidence 的正确性与自由文字的正确性分开评分，并制定“有效”“不可用”“异常”等词的允许含义。
