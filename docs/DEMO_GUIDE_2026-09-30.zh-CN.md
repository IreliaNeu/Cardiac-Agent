## 本次交流要回答什么

我们已经完成从心超双时相图像、左室心腔分割、面积计算，到三角色生成和审查报告的研究原型。它能保存每一步的图像、数值和角色记录，也能明确呈现工具失败。本次希望与老师共同确定：哪些证据对目标任务有用，什么情况下必须停止解释，以及下一阶段应怎样组织标注和评价。

## 1 输入与输出的含义

本轮使用 CAMUS 心脏超声 A4C 图像，每例提供一张舒张末期 ED 图像和一张收缩末期 ES 图像。它们不是完整心动周期视频。人工 mask 中的左室心腔标签用于独立评价，不作为模型预测或报告生成的输入。

| 对象 | 当前用途 | 不应误读为 |
| --- | --- | --- |
| ED 和 ES 原图 | 本地分割模型输入 | 连续运动序列 |
| 预测 LV 二值 mask | 面积计算与可视化 | 人工真值 |
| 人工 LV mask | 计算 Dice、IoU、参考 FAC | 给 Agent 的答案 |
| 结构化测量证据 | Analyst 和 Reviewer 的依据 | 图像已被语言模型审阅 |
| 中文报告 | 对可用证据及局限的研究性解释 | 自动临床诊断 |

## 指标定义

面积 A 为预测 mask 的非零像素数，单位为像素。代码支持在具备可靠像素间距时计算物理面积；本演示的像素数不能直接标作平方毫米。

面积比 R = A_ES / A_ED。

FAC = 100 × (A_ED − A_ES) / A_ED，单位为百分比。这里的 FAC 是双帧心腔面积变化率，不是左室射血分数 LVEF。FAC 绝对误差以百分点 pp 表示，例如 30% 与 20% 相差 10 pp。

Dice = 2 × 预测与人工交集 / 两者像素数之和；IoU = 交集 / 并集。展示页的“平均 Dice”先对单例 ED、ES 求均值；批次均值再对病例求均值。数值接近不能替代轮廓空间重合的检查。

## 输入不足时的处理

ES mask 为空时不输出 FAC 或面积比，避免把无法分割误写为完全收缩。ES 面积不小于 ED 时触发顺序异常质控，并要求人工复核。仅凭双帧心腔面积，不能判断局部室壁运动正常或异常。

讲解提示：先向老师确认本研究是否应继续使用这个面积指标，还是需要转向经明确测量协议定义的体积或时序任务。现有流程不能通过修改名称就把 FAC 变成 LVEF。

## 2 当前执行架构

流程主线如下；人工参考评价是旁路，不回流到语言模型。

输入 ED/ES 原图与元信息

↓ Planner 读取元信息，选择面积分析或附加探索性光流

↓ 本地 EchoNet DeepLabV3 ResNet50 分割 → ED/ES 预测 mask

↓ 确定性工具计算面积与 FAC → QC 标记 → 结构化证据包

↓ Analyst 读取计划与证据 → 生成报告草稿

↓ Reviewer 读取同一证据与草稿 → 生成最终报告及 limited/refer

↓ 程序执行硬性 QC 约束 → 保存图像、数值、报告和角色记录

独立评价旁路：预测 mask + 人工 LV mask → Dice/IoU 与 FAC 参考误差 → 评估文件和展示对照图。

## 3 三角色如何交互

三角色本轮使用相同的 Qwen/Qwen3-30B-A3B-Instruct-2507，服务来自 SiliconFlow。它们是不同角色提示和输入上下文下的三次调用，不是三个独立训练的模型。

| 角色 | 能看到什么 | 输出与权限 |
| --- | --- | --- |
| Planner | 视图、尺寸、ED/ES 信息、可用工具 | none/farneback 与分析重点；不能看图诊断 |
| Analyst | 计划、程序算出的数值、QC 与固定局限 | 保留原数值的 evidence 和中文草稿 |
| Reviewer | 同一证据包及 Analyst 草稿 | 最终文字、concerns、limited 或 refer |

本轮每例只有 Planner → 工具 → Analyst → Reviewer 一次顺序执行。Reviewer 不重新调用分割工具，不启动第二轮讨论。百例中 Planner 全部选择 none / area_only，因此没有通过这批数据验证工具规划的多样性或光流带来的收益。

## 程序约束与剩余盲点

程序要求报告中的 evidence 字典与输入完全一致，并校验文字中的阿拉伯数字是否可由输入数值按规定舍入得到。该检查能防止一部分数值捏造，但不能证明单位、因果关系、比值方向或中文数量表达都正确。

触边、面积不递减等阻断 QC 会强制最终状态为 refer；模型不能将其改为放行。limited 只表示受限研究输出，不表示临床正常；refer 表示需要人工复核，不表示阳性疾病。

角色请求与回应、请求哈希、模型信息和调用遥测均保留。相同请求可复用缓存，已失败的角色尝试不自动重放，以避免把重试伪装成一次讨论。这是过程缓存，不是长期记忆。

## 目前不是哪些能力

尚无自由多 Agent 辩论、自主修复闭环、经验证的 RWMA 分类器、临床知识检索或长期病例记忆。Farneback 接口只支持探索性稀疏心腔运动，不等同于心肌应变。三角色提示不同也不意味着审查意见相互独立。

讲解提示：“目前 Agent 的自主性主要是有限工具选择与证据审查。我们需要先证明它们比单次报告生成更可靠，再考虑扩大权限和增加讨论轮数。”

结果来自 three-role-100-20260927-delivery；原始实验目录保持不变。下列数字衡量流程与分割结果，不是临床诊断准确率。

## 写论文前还缺什么

首批 3 例曾用于开发且包含在百例中，本批不能称为独立留出测试。patient0033 与 patient0068 的 ED 图像哈希相同，ES 不同；100 对 ED/ES 的组合不同，但划分数据时仍需检查重复图像和患者来源。

目前没有匹配预算的单 Agent、固定流水线和三角色对照，没有医生盲评，也没有临床终点标签验证。因此可以说“实现并验证了可追溯流程”，不能说“已证明多 Agent 提升临床准确率”。

## 5 较好结果与误差抵消

### patient0020 完整链条示例

筛选规则：当前 QC 未触发、最终 limited 且 FAC 绝对误差不超过 5 pp 的病例中，选择 Dice 最高者。5 pp 仅为演示筛选规则，不是临床阈值。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 43169 | 45007 |
| ES 心腔像素数 | 30343 | 32117 |
| FAC | 29.7111% | 28.6400% |
| ED / ES Dice | 0.9543 / 0.9192 | 平均 0.9368 |
| FAC 绝对误差 | 1.07 pp | 状态 limited |

展示动作：先看两张原图，再看绿色预测叠加，最后打开青色预测与橙色人工轮廓对照。指出数值来自预测，而不是从人工标注复制。展开三个角色记录，说明文字和计算是如何衔接的。

讲稿：“这例用来理解系统的完整输出。模型与人工轮廓较一致，但它是有意挑选的较好例子，不能据此代表整体性能。”

### patient0004 两相位同时少分

筛选规则：选择 Dice 最接近完成计算的 98 例中位数的 QC 清洁病例。该批中位数为 0.8616；本例均值为 0.8622。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 24049 | 31799 |
| ES 心腔像素数 | 14154 | 18605 |
| FAC | 41.1452% | 41.4919% |
| FAC 绝对误差 | 0.35 pp | 状态 limited |

两相位都少分了约四分之一，面积比却相近。说明 FAC 误差小可能来自误差抵消，不一定表示边界分割准确。接近本批中位数，也不意味着具有临床代表性。

向老师提问：评价指标是否应同时约束分割边界、测量偏差和失败检出，而不能仅按面积变化误差排名？

## 6 当前 QC 的盲点与有效拦截

### patient0042 报告流畅但分割严重偏差

筛选规则：当前 QC 未触发且最终 limited 的病例中，选择平均 Dice 最低者。这一例用于暴露盲点，而不是展示整体均值。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED / ES 像素数 | 17990 / 12078 | 31269 / 24566 |
| FAC | 32.8627% | 21.4366% |
| ED / ES Dice | 0.6294 / 0.0868 | 平均 0.3581 |
| FAC 绝对误差 | 11.43 pp | limited；当前 QC 未触发 |

展示动作：重点看 ES 的双轮廓图。像素数量仍满足 ES 小于 ED，但预测区域与人工区域几乎不重合。Reviewer 看不到原图和人工 Dice，因此仅靠数值顺序无法识别这种错误。

原报告中的比值表述应按结构化字段 ES/ED 理解，不能把文字中含混的“ED 与 ES 面积比值”当作定义。页面保留原报告，并把这项解释放在独立旁注中。

讲稿：“这是目前最值得改进的一环。语言审查不能弥补它没有收到的图像质量证据。下一步应增加不依赖人工标签的分割质量评估，再评估 Agent 能否正确使用这类信号。”

### patient0039 顺序异常被强制转人工

筛选规则：完成计算且被 QC 转人工的病例中，选择平均 Dice 最低者。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED / ES 像素数 | 18989 / 27515 | 34118 / 19433 |
| FAC | −44.8997% | 43.0418% |
| 平均 Dice | 0.0088 | FAC 误差 87.94 pp |
| 处置 | refer | 面积顺序 QC 强制复核 |

负 FAC 是程序对异常预测面积按公式计算的结果，不是负射血分数，更不是疾病结论。需要医生回看图像核查分割和时相。该例证明一条规则能够发现某类异常，但不能推论它能覆盖上一例那样的空间错位。

## 7 空分割及报告语义问题

### patient0033 工具失败也必须留痕

筛选规则：按病例编号选择第一个已生成失败报告的空 mask 病例。它的 ES 二值图为全零，预测叠加图中没有绿色区域，并非展示页加载失败。

| 指标 | 预测 | 人工参考或独立评价 |
| --- | --- | --- |
| ED 心腔像素数 | 13461 | 31077 |
| ES 心腔像素数 | 0 | 13219 |
| ED / ES Dice | 0.6045 / 0.0000 | 平均 0.3022 |
| 模型 FAC 与面积比 | 不可用 | 人工参考仅用于独立评价 |
| 处置 | refer | 空预测 mask，工具失败报告 |

展示动作：先打开 ES 二值图，确认是全零预测；再对比人工轮廓，最后阅读“无法计算”的原报告。强调系统没有将人工标注替换成模型分割，也没有把失败记为 FAC 等于 100%。

## 不要隐藏原报告中的问题

原文称“ED相位掩码有效”。现有证据最多支持它非空，不能据此说分割准确。本例 ED Dice 为 0.6045，必须区分格式或可计算性与解剖准确性。

原文把 RWMA 不可用归因于输入缺失，也不完整。当前项目实际上没有部署经验证的 RWMA 分类器，即使分割成功，也不能生成可靠的局部室壁运动分类。

这些句子作为原模型输出被原样保留。讲解旁注是本次整理者的说明，不是模型重新生成的“改进版”。这也说明保持 evidence 数值一致不能保证解释语义无误。

## 从本例引出的优化

建议将可计算、分割可信和临床可解释分为不同状态；报告中分别列出“工具未部署”“输入不足”“QC 阻断”。对失败原因采用可追踪错误码，并检查模型文字是否与错误码一致。

失败数据不应从结果表中消失。论文中应同时报告总请求数、测量成功数、失败原因和条件性能，不能只保留容易成功的病例。

## 9 与医工老师确认的事项

### 先明确研究终点

本项目优先解决分割质控、定量测量解释，还是 RWMA 判别？三者所需输入与标签不同。请明确目标解剖结构、视图、疾病范围以及预期使用者，再决定是否采集完整视频、多视图或其他临床信息。

### 统一标注和测量协议

### 定义何时必须拒答或转人工

请老师针对五例标注：分割是否可接受、测量是否可用、哪些错误必须拦截，以及报告中哪些措辞可能造成误解。尤其检查“数值合理但区域错误”的病例，帮助设计形状、视图、置信度或时序一致性质量信号。

### 设计报告评价

建议盲评事实一致性、错误归因、限制说明、遗漏和潜在误导，同时记录修改时间。把结构化 evidence 的正确性与自由文字的正确性分开评分，并制定“有效”“不可用”“异常”等词的允许含义。
