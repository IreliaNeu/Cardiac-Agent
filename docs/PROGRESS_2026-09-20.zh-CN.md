## 最小复现命令

```bash
conda activate cardiac-agent
python -m cardiac_agent.smoke --output runs/smoke-new
python -m cardiac_agent.smoke \
  --study data/camus-pilot-20260910/converted/patient0001-4CH/study.json \
  --output runs/smoke-real-new
# 有 OpenCV 和 API 配置时：
python -m cardiac_agent.smoke \
  --study data/camus-pilot-20260910/converted/patient0001-4CH/study.json \
  --output runs/smoke-api-new --deformation farneback --qwen --env .env
```

output 必须是新目录；当前 smoke 的输入为合成或人工 mask，模型完整对照继续使用
`scripts/evaluate_segmentation.py`。RWMA unavailable 允许工程验收通过，不代表分类模型完成。
