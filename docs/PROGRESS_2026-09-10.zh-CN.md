# Phase M2：CAMUS 真实人工标注小样本验证

## 目标与结论

在服务器 RTX 4090 已恢复的情况下，先验证真实心超图像的人工 mask 路径。本路径不需要 GPU，因此没有安装或运行分割网络。3 个病例、各 2CH/4CH，共 6 组 ED/ES 流程全部完成。本结果证明数据读取、计算和信息传递可执行，不是分割性能、诊断准确率或论文效果验证。

## 数据来源与范围

- 官方说明：https://www.creatis.insa-lyon.fr/Challenge/camus/databases.html
- 官方 Girder API：https://humanheart-project.creatis.insa-lyon.fr/database/api/v1
- CAMUS_public collection：`6373703d73e9f0047faa1bc8`
- database_nifti folder：`63fde55f73e9f004868fb7ac`
- 按目录名选择 `patient0001`、`patient0002`、`patient0003`，不是随机抽样或正式训练/测试划分。
- 下载 24 个 NIfTI 文件（12 张图像、12 张人工标注）及每病例的两份 Info 配置和引用要求，共 33 个文件。未下载完整序列或全集。
- `download_manifest.json` 保存官方下载 URL、item ID、文件字节数和 SHA256；原始文件保留在 raw 目录。
- 本次使用 NIfTI 重发布版本，不套用早期 MHD 版本的固定 spacing。样本读取到的 spacing 约为 0.308 x 0.308 mm。
- 保留多类标签，功能计算仅使用 label=1 的 LV cavity；人工标注不视为 RWMA 标签。
- 数据不推送公开代码仓库，后续使用须遵守官方数据条款并引用 Leclerc et al., IEEE TMI 2019, doi:10.1109/TMI.2019.2900516。

FAC 是二维腔室面积变化比例，不是 LVEF。强度差不是物理形变或心肌应变。RWMA 保留 unavailable，不输出标签或概率，也不计算虚假的准确率。人工 mask 自身的逐像素一致性不报告为模型 Dice。

## API 与当前限制

本轮将真实病例指标发送到外部 Qwen API 的步骤被安全审查阻止，尚待用户对传出本轮医学指标的明确授权。本轮实际运行没有读取 API 凭据，也没有向外部 LLM 发送图像、标注或指标；使用本地模板解释。上一阶段合成数据的 Qwen API 成功结果不冒充本轮真实数据验证。

本次没有运行 EchoNet，没有训练 RWMA，没有建立医学 Web Demo。现有 API 解释仍限于事实组织，非自由临床推理。

## 产物与复现

服务器：`/root/autodl-tmp/Cardiac-Agent/data/camus-pilot-20260910/`
